# Cypher GM Taskbar v2.0.0

A GM-only taskbar for Foundry VTT's Cypher System.

## Features

- **Party Overview** — Live pool bars, tier, effort, XP, damage track status for all PCs
- **Combat Tracker** — Difficulty dial (with TN), combatant list, round counter
- **GM Intrusions** — Log and track intrusions with timestamps
- **Cyphers & Artifacts** — Browse all PC cyphers by character
- **Recovery Rolls** — Track 1st/2nd/3rd/4th recovery per PC
- **NPC Quick List** — Browse and open NPC sheets
- **GM Notes** — Persistent quick-notes panel
- **Settings** — Dock top/bottom, opacity, compact mode

## Installation

Extract to `Data/modules/cypher-gm-taskbar/` and enable in Foundry.

## Requirements

- Foundry VTT v13+
- Cypher System v2+

## Usage

Only renders for GMs. Click any button to open its panel. Click again to close.
