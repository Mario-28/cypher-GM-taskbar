# Cypher GM Taskbar v3.17.32

A GM-only taskbar for Foundry VTT's Cypher System.

## Features

- **Party Overview** — Live pool bars, tier, effort, XP, damage track status for all PCs
- **Combat Tracker** — Difficulty dial (with TN), combatant list, round counter
- **GM Intrusions** — Log and track intrusions with timestamps
- **Cyphers & Artifacts** — Browse all PC cyphers by character
- **Recovery Rolls** — Track 1st/2nd/3rd/4th recovery per PC
- **NPC Quick List** — Browse and open NPC sheets
- **GM Notes** — Persistent quick-notes panel
- **Settings** — Dock top/bottom, opacity, compact mode
- **CALL ROLL** — GM can trigger Cypher Taskbar roll dialogs on player screens!

## CALL ROLL Integration (v3.17.32+)

When a player has **Cypher Taskbar** installed (patched v2.7.26-gmroll+), the GM can:
- Click **CALL ROLL** on any PC's pool → player's Cypher Taskbar roll dialog opens
- Click **CALL ROLL** on any skill → player's Cypher Taskbar skill roll dialog opens

The player's native Cypher Taskbar dialog opens with:
- Difficulty pre-set from GM's target difficulty
- All the familiar fields: Assets, Effort, Edge, Ease, Hindrance
- Live difficulty/target preview
- Full Cypher Taskbar styling

## Installation

Extract to `Data/modules/cypher-gm-taskbar/` and enable in Foundry.

## Requirements

- Foundry VTT v13+
- Cypher System v2+
- Cypher Taskbar v2.7.26-gmroll+ (for CALL ROLL feature)

## Usage

Only renders for GMs. Click any button to open its panel. Click again to close.
